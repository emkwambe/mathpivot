# MathPivot Infrastructure Directive

## Foundational Reality

MathPivot is not primarily a tutoring business.

MathPivot exists to build the infrastructure that enables excellent math coaches to consistently produce strong student outcomes at scale.

## Primary Customers (in order of strategic importance)

1. The MathPivot Coach
2. The School Partner
3. The Learning Center Operator
4. The Homeschool Organization
5. The Parent
6. The Student

## Infrastructure Layers

### Layer 1: Diagnostic Infrastructure
- Placement accuracy
- Gap identification
- Mastery tracking
- Reusable data
- **Outputs:** Diagnostics, placement reports, readiness scores, progress dashboards, mastery maps

### Layer 2: Curriculum Infrastructure
- Teachable by multiple instructors
- Standardizable
- Licensable
- Measurable
- **Outputs:** Atomic concepts, lesson sequences, practice systems, summer clinics, assessment banks, intervention plans

### Layer 3: Coach Infrastructure
- Good teacher → great MathPivot coach
- Reduced training time
- Improved consistency
- Improved coaching quality
- **Outputs:** Coach certification, training modules, session playbooks, observation rubrics, calibration systems, coaching standards

### Layer 4: Operating Infrastructure
- Repeatable across locations
- Automatable
- Scalable without founder dependency
- **Outputs:** Enrollment workflows, scheduling systems, parent communication, session tracking, reporting, quality assurance

### Layer 5: Network Infrastructure
- Increases value of being a MathPivot coach
- Strengthens the network
- Creates network effects
- **Outputs:** Coach community, resource libraries, shared assessments, shared curriculum, master coach system, licensing platform

### Layer 6: Market Infrastructure
- Helps coaches acquire students
- Lowers customer acquisition cost
- Increases retention
- Improves conversion
- **Outputs:** Summer clinics, diagnostic events, referral systems, school partnerships, parent workshops, community outreach

### Layer 7: Data Infrastructure
- Generates strategic data
- Improves future outcomes
- Becomes competitive advantage
- **Outputs:** Student mastery database, cohort benchmarks, coach performance metrics, curriculum effectiveness data, placement intelligence

## Rules

### Pricing Rule
Never price based on tutoring hours. Always price based on value delivered.
- What outcome is being created?
- What capability is being enabled?
- What risk is being removed?
- What future opportunity is being unlocked?

### Scalability Rule
Reject any proposal that requires the founder to personally deliver the service long-term.
Prefer systems that can be: documented, taught, certified, measured, licensed, automated.

### Decision Test
For every recommendation:
1. Does this improve student outcomes?
2. Does this strengthen the MathPivot Method?
3. Does this help another coach succeed?
4. Does this increase scalability?
5. Does this create reusable intellectual property?
6. Does this generate valuable data?
7. Could this work in Ohio, Texas, North Carolina, or any other state with a trained coach?

If the answer is no to most of these, reconsider the recommendation.

## Mission

MathPivot's mission is not to teach every student. MathPivot's mission is to build the infrastructure, systems, curriculum, assessments, training, certification, and operating model that enable thousands of students to receive exceptional math coaching through a network of highly capable MathPivot coaches.
