# MathPivot: Strategic Business Positioning & Development Blueprint

## Part 1 — Strategic Positioning

### 1.1 The Gap

No company owns the full middle-school math development pipeline — combining
mastery-based coaching, competition preparation, applied career experiences,
and outcome-based pricing in a single subscription relationship.

**Market context (research-validated):**
- K-12 online tutoring: $6.8B (2025) → $19.9B by 2034 (12.3% CAGR)
- Families pursuing elite math pathways spend $3,000–$10,000+/year
- Youth sports: $40B+ industry, 60M kids, avg family spends $1,016/year (up 46% since 2019)
- 70% of youth athletes drop out by age 13 — the exact age MathPivot targets

**The insight:** Families already sacrifice for structured development when
they believe the pathway is real. Youth sports is the proof. Non-athletic
children deserve an equally structured, aspirational pathway.

### 1.2 Category Creation

MathPivot is not a tutoring platform. It is an **Academic Performance System**.

**Category:** Professional Pathway Preparation

**Positioning statement:**
> MathPivot applies the structure, discipline, and coaching model of athletics
> to academic and professional development — giving students a clearer and more
> attainable path to high-impact careers.

**Core message (parent-facing):**
> "Sports builds character. MathPivot builds careers."

**Balanced version:**
> "We bring the discipline of sports training to academic and career success —
> where opportunities are far more attainable."

### 1.3 Competitive Landscape

| Company | Model | Pricing | Coach Relationship | Gap |
|---|---|---|---|---|
| Kumon | Worksheet drill, rotating staff | $140–200/mo | None | No coaching, no career exposure |
| Mathnasium | Center-based, semi-consistent | $250–400/mo | Weak | No structured progression |
| AoPS | Structured courses, no named coach | $240–500/course | None | No 1:1 mentorship |
| AlphaStar | Competition-tier courses | $300–600/course | Weak | No applied experience |
| Private tutoring | Hourly, transactional | $40–120/hr | Variable | No system, no accountability |
| **MathPivot** | **Program-based, named coach** | **$199–900/mo** | **Long-term** | **Full pipeline** |

### 1.4 Differentiation Framework

| Dimension | Traditional Tutoring | MathPivot |
|---|---|---|
| Unit of sale | Hour | Program (mastery) |
| Relationship | Transactional | Coaching (long-term) |
| Curriculum | Reactive (homework help) | Atomic (structured objectives) |
| Tracking | Minimal | Mastery progression |
| Career connection | None | Integrated exposure |
| Competition | None | Strategic calendar |
| Identity | "I need help" | "I'm preparing for engineering" |

## Part 3 — Coach Model

### 3.1 Role Definition

MathPivot Coaches are NOT tutors. They are:
- Career-aligned mentors
- Performance trainers
- Long-term developmental partners (like a travel ball coach)

### 3.2 Capacity Constraints (Quality Control)

| Constraint | Limit | Rationale |
|---|---|---|
| Max students (portfolio) | 15 | Relationship depth |
| Max concurrent per session | 5 | Attention quality |
| Max sessions per day | 2 | Prevent burnout |
| Default weekly sessions | 4 | Quality baseline |
| Scalable to | 6–8/week | Only if outcomes stay strong |

### 3.3 Compensation Model

Revenue sharing: Coach earns percentage of program price.

**Example at 60% share:**
- Foundation: $299 × 15 students × 60% = **$2,694/mo**
- Mixed portfolio (Foundation + Acceleration): ~**$3,500–4,500/mo**
- With premium add-ons (testing, competition prep, summer): up to **$5,000+/mo**

**Value multipliers:**
- Reduced prep time (system-generated content, atomic curriculum)
- Stable recurring income (not hourly scrambling)
- Professional identity and growth path
- Revenue upside through specialization

### 3.4 Session Model

Each session (60–90 min) must produce:
1. Concept introduction or reinforcement (atomic objective)
2. Guided practice with active engagement
3. Validated understanding
4. Mastery classification (not started / developing / proficient / mastered)

### 6.2 What Needs to Change (Tutoring → Coaching Model)

| Current | Target | Effort |
|---|---|---|
| "Book Session" (hourly) | "Enroll in Program" (monthly) | **Large** — new enrollment flow |
| "Tutor" role label | "Coach" role label | **Small** — rename across UI |
| Credit-based billing | Subscription billing (Stripe) | **Medium** — recurring payments |
| Ad hoc sessions | Program calendar (weekly schedule) | **Medium** — scheduled sessions |
| No mastery tracking UI | Student mastery dashboard | **Medium** — visualize skill progression |
| No career exposure | Career module system | **Large** — new content system |
| No competition tracking | Competition calendar + results | **Medium** — new pages |
| "Sessions completed" metric | "Concepts mastered" metric | **Small** — metric relabeling |
| Per-session booking | Ongoing enrollment with coach | **Large** — relationship model |

### 6.3 What to Keep As-Is
- Auth system (audited, solid)
- RLS policies (comprehensive)
- Messaging (works, upgrade to realtime later)
- Admin dashboard (functional)
- Email infrastructure (Resend, verified)
- Deployment pipeline (Vercel, working)

## Part 7 — Development Sprints

### Sprint 0: Foundations (Week 1–2)
**Goal:** Rebrand and restructure without breaking existing functionality.

- [ ] Rename "Tutor" → "Coach" across all UI (sidebar, headers, role labels)
- [ ] Rename "Book Session" → "Schedule Session" (interim, before program model)
- [ ] Update landing page messaging to reflect coaching positioning
- [ ] Add `programs` table if not exists (id, name, track_level, description, monthly_price, max_students)
- [ ] Add `program_enrollments` table (student_id, program_id, coach_id, enrolled_at, status)
- [ ] Update Supabase Auth redirect URLs for production domain

### Sprint 1: Program Enrollment (Week 3–4)
**Goal:** Replace ad-hoc booking with program-based enrollment.

- [ ] Build program catalog page (Foundation / Acceleration / Elite)
- [ ] Build enrollment flow (parent selects program → assigns student → picks coach)
- [ ] Wire Stripe subscription billing (recurring monthly charges)
- [ ] Replace credit purchase with subscription checkout
- [ ] Build coach portfolio view (see all enrolled students, not just upcoming sessions)
- [ ] Add coach capacity constraints (max 15 students, enforce in enrollment)

### Sprint 2: Mastery Tracking (Week 5–6)
**Goal:** Make learning outcomes visible and measurable.

- [ ] Design atomic concept taxonomy (subject → topic → concept)
- [ ] Build mastery tracking UI for coaches (mark concepts per session)
- [ ] Build student mastery dashboard (visual progression)
- [ ] Build parent mastery report (weekly/monthly email summary)
- [ ] Integrate mastery data into existing certification engine
- [ ] Add mastery-based badges (repurpose Open Badges infrastructure)

### Sprint 3: Competition & Career (Week 7–8)
**Goal:** Add the two differentiators that no competitor has.

- [ ] Build competition calendar page (AMC 8, MATHCOUNTS, local events)
- [ ] Add competition tracking per student (registered, participated, score)
- [ ] Build career exposure module system (short videos/articles per math concept)
- [ ] Create initial career module content (5–10 modules covering key professions)
- [ ] Add career exposure tracking (which modules each student has completed)
- [ ] Build "My Journey" student view (mastery + competitions + career modules)

### Sprint 4: Coach Economics (Week 9–10)
**Goal:** Make the coach compensation model real.

- [ ] Build coach earnings dashboard (monthly revenue, student count, projections)
- [ ] Implement revenue sharing calculation (program price × share %)
- [ ] Build coach payout system (or Stripe Connect for direct deposits)
- [ ] Add coach performance metrics (retention, mastery delivery rate)
- [ ] Build coach onboarding flow (application → review → activation)

### Sprint 5: Polish & Launch (Week 11–12)
**Goal:** Production-ready for first cohort of coaches and families.

- [ ] End-to-end testing of enrollment → session → mastery → billing flow
- [ ] Mobile responsiveness audit
- [ ] Accessibility audit (axe-core, keyboard navigation)
- [ ] Load testing (simulate 50 concurrent users)
- [ ] Marketing site updates (testimonials, pricing page, FAQ)
- [ ] Coach recruitment materials
- [ ] Parent onboarding documentation
- [ ] Soft launch with 3–5 coaches, 20–30 students

## Part 8 — Guardrails

### 8.1 Product Guardrails
- **Never sell hours.** Every offering is a program with defined outcomes.
- **Never rotate coaches.** Each student has a named coach for the duration.
- **Never exceed capacity.** 15 students per coach is a hard cap, not a suggestion.
- **Never skip mastery tracking.** Every session must produce a measurable outcome.
- **Never promise specific career outcomes.** Promise structured exposure and preparation.

### 8.2 Messaging Guardrails
- **Never attack sports.** Sports builds discipline — MathPivot applies that same
  discipline to academics where opportunities are broader.
- **Never guarantee grades.** Guarantee structure, coaching, and exposure.
- **Never use fear-based marketing.** Use aspiration: "Your child's future is worth
  the same investment as travel ball."
- **Never claim to replace school.** MathPivot supplements and accelerates.

### 8.3 Financial Guardrails
- **Coach share never below 55%.** If the model doesn't work for coaches, it doesn't work.
- **Minimum 3-month enrollment.** Mastery requires time — monthly churn kills the model.
- **No discounting the core program.** Scholarships yes, discounts no.
- **Scholarship fund:** Reserve 5% of revenue for need-based access.

### 8.4 Quality Guardrails
- **Session quality audits:** Random session reviews monthly.
- **Student progress reviews:** Coach reviews every student's mastery quarterly.
- **Parent check-ins:** Platform-initiated parent satisfaction surveys at 30/90/180 days.
- **Coach development:** Monthly coach training sessions on curriculum and pedagogy.

### 8.5 Technical Guardrails
- **No feature without measurement.** Every new feature must have associated metrics.
- **No rewrites.** Iterate on the existing codebase — it works.
- **Mobile-first.** Parents check progress on phones.
- **Accessibility.** WCAG 2.1 AA compliance target.

|---|---|---|---|
| Billing model | Credits vs Stripe subscriptions | Subscriptions (monthly recurring) | Sprint 1 |
| Coach compensation | Fixed rate vs revenue share | Revenue share (60/40) | Sprint 4 |
